#   compare_accuracy.py 精度对齐对比与画图
#   perf_collector.py   日志指标提取（STEP_TIME / GBS / samples/s）
#   demo.py             Gradio 推理演示

# ---------------------------------------------------------------- 说明
# 1. 不要用 `pip install -e .` 安装本目录 —— 依赖版本会与镜像预置的 torch/torch_npu 冲突。
#    按本清单逐项补装即可（先在干净环境执行 `pip install -r requirements.txt`）。
# 2. transformers 若被上游自动升到与镜像不匹配的版本，会破坏 torch_npu 的算子注册；
#    装完请执行 `python -c "import torch, torch_npu; print(torch.npu.is_available())"` 校验。
# 3. fla_npu 算子库（AscendC GDN 算子）不在 pip 生态内，需按 console/install_fla_npu.sh 从源码编译安装。
#    未安装时 main.py 会自动探测并回落到 eager 路径（见 main.py: detect_gdn_implementation）。
